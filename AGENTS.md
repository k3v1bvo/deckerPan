## 📋 The 6-Stage Execution Flow

Whenever developing new features or refactoring:
1. **DEFINE**: Clarify the exact user story, constraints, and business logic.
2. **PLAN**: Outline component hierarchy, database schemas, and state interactions.
3. **BUILD**: Implement using strict TypeScript, authentic photos, and semantic Tailwind classes.
4. **VERIFY**: Run `npm run build` and launch the browser subagent to visually confirm responsiveness.
5. **REVIEW**: Verify zero regression, correct sound/realtime hooks, and crisp typography.
6. **SHIP**: Fast-forward git commits, push to remote, and keep dev servers running stably.
